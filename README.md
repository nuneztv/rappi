# Laboratorio 4 - Sistema de Delivery

## Base de datos
1. Crear la base de datos `rappi_lab` en PostgreSQL (vacia).
2. Poner tu password en `server/src/db/connection.ts`.
3. Las tablas se crean solas con `initDB()` (`server/src/db/initDB.ts`) cuando se inicia el servidor.

## Servidor (puerto 4000)
cd server
npm install
npm run dev

## Cliente (puerto 3000)
cd client
npm install
npm run dev
